# 🩺 DataDoctor AI

DataDoctor AI is an automatic data analysis and cleaning application built with Python and Streamlit.

The goal of the project is to allow users to upload messy datasets without writing Python code.

## 🚀 Features

- 📂 CSV and Excel file upload
- 📊 Dataset overview
- 🔍 Automatic data insights
- 🕳️ Missing value detection
- 📑 Duplicate detection
- 📦 Outlier detection
- 📈 Skewness analysis
- 🔗 Correlation analysis
- 📊 Automatic visualizations
- 🧹 Cleaning recommendations
- ✨ Automatic data cleaning
- ⭐ Data quality score
- 🤖 AI-style data recommendations
- 🔄 Before vs After comparison
- 📄 PDF report generation
- 📥 Download cleaned dataset

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- ReportLab
- OpenPyXL
